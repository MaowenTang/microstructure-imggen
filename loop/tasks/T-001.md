### repo_map.md required entries (each with an existing, `test -e`-verified path)

1. Repo root absolute path; git status (branch, remote if any, clean/dirty).
2. Dataset root: directory of the 512×512 patches; total patch count; count
   in the training region (normalized x ≤ 0.60) and validation region
   (x ≥ 0.80); where patch coordinates live (filename convention or index
   file).
3. Trained autoencoder checkpoint used by the paper (path + file mtime/size).
4. Diffusion checkpoints per variant (base / global / spatial / sobel /
   grayscale / RGB-curated / process-9 expert): path, training step count,
   whether EMA weights are stored separately.
5. Training entry scripts + config files for AE and diffusion (paths; the
   command line that reproduces the paper's base 10k-step run, as found in
   code or scripts — do not invent; if not recoverable, say so).
6. Evaluation / descriptor code: where Sobel edge mean, orientation
   coherence, FFT ripple spacing, ripple/radial score, and the
   nearest-neighbor-ratio (handcrafted feature space + leave-one-out
   normalization) are implemented; the curation rule for the "750 curated
   reference patches" if present in code — quote the rule, else write
   "not found in repo".
7. Python environment activation line (module load + venv/conda) that the
   training scripts actually use.
8. GPU types visible on this cluster for the gpu partition
   (`sinfo -p gpu -o "%G %D"`), and GPU type used by any past project jobs if
   discoverable from existing sbatch scripts.
