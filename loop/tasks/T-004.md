## Background

Current training: 10,000 steps at effective batch 8 over ~2,400 training
patches ≈ 33 epochs — short for diffusion. NN ratio 1.19 (paper §V) shows no
memorization, i.e., the data is not yet exhausted; if the gap is
undertraining, more steps close it; if capacity, the gap plateaus while NN
ratio stays high; if the data ceiling, the gap plateaus while NN ratio falls
toward 1 (memorization onset). Reference statistics: UNCURATED full
validation region (primary; per loop/DECISIONS.md) and the curated set as
secondary if T-001/T-002 located its rule. Paths from
`results/T-001/repo_map.md`.
