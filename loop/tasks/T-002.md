## Goal (stop condition)

The paper's Table-I gap is decomposed into an AE-attributable share and a
diffusion-attributable share, by measuring the same morphology descriptors on
real validation patches versus their encode–decode reconstructions. After
this task we know the hard ceiling any latent-diffusion result can reach
through the current decoder.

## Background

The paper reports generated-vs-real gaps (Sobel edge mean 0.363 vs 0.628;
orientation coherence 0.029–0.030 vs 0.070; FFT spacing 41.8–42.7 vs
39.4 px; ripple score 0.333–0.349 vs 0.416) but never measures its own retrained AE
(5,000 steps, loss = Charbonnier + 0.10·SSIM + 0.05·edge + 0.05·FFT). In
latent diffusion the decoder bounds sample fidelity: if reconstructions of
real patches already lose edge strength, that loss is not recoverable by any
amount of diffusion training. All paths below come from
`results/T-001/repo_map.md`.

**Dispatch gate: T-001 ACCEPTED and `task/T-001` merged into main** (this
task reads `results/T-001/repo_map.md`); verify
`git merge-base --is-ancestor task/T-001 main` before starting.

## Deliverables

- [ ] `src/morph_eval.py` — the project's ONE descriptor harness, reused
      verbatim by T-003/T-004/T-005: a thin wrapper around the repo's
      existing descriptor code (repo_map entry 6) exposing
      `compute_descriptors(image) -> dict` with keys `sobel_edge_mean`,
      `orientation_coherence`, `fft_spacing_px`, `ripple_score`, plus
      `reference_stats(patch_paths) -> dict` (mean/sd per key) and
      `nn_ratio(samples, train_feats)` for the handcrafted-space ratio with

      asserts the wrapper reproduces the original code's numbers exactly

      encode–decodes a given patch list, computes per-patch: (a) recon
      metrics: SSIM, PSNR, edge MAE, FFT spectral deviation; (b) the four
      descriptors via `src/morph_eval.py` on BOTH the raw patch and its

- [ ] `results/T-002/recon_metrics.csv` — one row per validation patch,

## Constraints
