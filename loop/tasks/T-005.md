## Goal (stop condition)

Quantifies how much of the Table-I gap closes with zero training — sampler
steps, ancestral vs DDIM, EMA on/off, and guidance scale — so the paper's
final sampling configuration is a measured choice instead of a default, and
the unexplained guidance switch (2.0 default vs 1.0 for the process-9 expert)
gets its missing justification.

## Background

The paper samples with DDIM-150 and EMA weights, guidance 2.0 for conditional
runs, 1.0 for the process-9 expert — none of these swept. Sampler settings
routinely move sharpness-type statistics (Sobel edge mean) by meaningful
margins. This task only READS existing checkpoints (from
`results/T-001/repo_map.md` entry 4). Reference statistics: uncurated full
validation region (per loop/DECISIONS.md).

**Dispatch gate: T-002 ACCEPTED and `task/T-002` merged into main** — this
task imports the shared descriptor harness `src/morph_eval.py` that T-002
delivers, and must not reimplement any descriptor (loop/DECISIONS.md,
one-harness rule). Cut your branch from main only after that merge; verify
with `git merge-base --is-ancestor task/T-002 main` before starting, and
stop with a report if it fails.
Independent of T-003/T-004; may run in parallel with T-003.

## Constraints

- HPC budget: gpu_debug only, ≤ 2 jobs, each `--time` ≤ 01:30:00, total
  ≤ 2 GPU-hours. DDPM-1000 and DDIM-500 cells are the slow ones — if the
  budget projection is tight, drop DDIM-500 × EMA-off first and record it
  as `DEVIATION: dropped-cell` in the report.
- Pilot (mandatory, AGENTS.md rule 5): job 1 = one base cell
  (DDIM-150, EMA on) × 8 samples, `--time` ≤ 00:15:00; sanity-check the CSV
  row and the wall-seconds-per-sample before submitting job 2 = the full
  grid, sized from that measurement.
- Fixed seeds (9090 + offsets) shared across cells so cells differ only by
  the knob; seeds logged in grid.csv.
- Checkpoints are read-only; samples under
  `/scratch/user/$USER/microimagegen/T-005/`.
